# 病院アンケートシステム

病院向けオフライン・アンケートシステム。Windows デスクトップアプリケーション（.exe 形式）として動作し、院内 LAN の共有フォルダを利用してデータを管理します。

## 機能

- **複数アンケート管理**: 「感染対策研修」「満足度調査」など複数を作成・公開/非公開・削除。回答者は公開中のものから選択
- **アンケート作成（管理者モード）**: 単一選択・自由記述の設問作成、設問の並び替え、条件分岐（特定回答時のみ表示）、PDF 参照リンク、パスワード保護
- **回答期限**: 開始日・終了日を設定し、期間外は回答不可
- **匿名モード**: 氏名を記録せず部署のみ保存（率直な意見の収集向け）
- **アンケート回答**: 部署・氏名連動プルダウン、必須項目バリデーション、回答済みチェック（修正対応）
- **ログ収集**: 起動時に端末名・IP・日時を自動記録
- **集計・出力**: 回答データの自動集計（棒グラフ／円グラフ切替・部署フィルタ）、部署別回答率グラフ、未回答者抽出、CSV エクスポート
- **共有フォルダ運用**: 院内 LAN の共有フォルダにデータを集約。ファイルロックで同時書き込みの衝突を防止
- **回答データのバックアップ**: 保存時の日次自動バックアップ＋手動バックアップ
- **バージョン更新チェック**: 共有フォルダの最新バージョンと比較し、古い端末に更新を促す

## プロジェクト構成

```
├── main.py              # エントリポイント
├── src/
│   ├── app.py           # メインアプリケーション（GUI）
│   ├── config.py        # 設定定数
│   ├── data_manager.py  # データ読み書き（CSV/JSON）
│   ├── file_lock.py     # ファイルロック（排他制御）
│   ├── gui_admin.py     # 管理者モード画面
│   ├── gui_aggregate.py # 集計・出力画面
│   ├── gui_response.py  # 回答者モード画面
│   └── logger.py        # 操作ログ収集
├── data/
│   ├── master_user.csv          # 職員マスターデータ
│   └── surveys/                 # アンケート（複数）
│       └── <survey_id>/
│           ├── config.json      # 設問・期限・匿名設定など
│           ├── answers.csv      # 回答データ（実行時生成）
│           └── backups/         # 回答バックアップ（実行時生成）
├── tests/               # ユニットテスト
├── build.spec           # PyInstaller ビルド設定
└── requirements.txt     # 依存パッケージ
```

## 共有フォルダ運用

exe を各クライアント端末に配置し、データは院内 LAN の共有フォルダに集約します。
初回起動時に共有フォルダのパスを指定でき、`local_settings.json`（exe 同階層）に保存されます。
環境変数 `HOSPITAL_SURVEY_DATA` でも指定可能です。

共有フォルダ内のファイル構成:

| ファイル/フォルダ | 用途 |
|---|---|
| `master_user.csv` | 部署と氏名の紐付けリスト |
| `surveys/<id>/config.json` | アンケート設問設定 |
| `surveys/<id>/answers.csv` | 回答データの蓄積 |
| `app_config.json` | 管理者パスワード等のグローバル設定 |
| `version.json` | 更新チェック用の最新バージョン情報 |
| `access_log.txt` | 端末名・IP・時間のログ |

## 実行方法

```bash
python main.py
```

## exe ビルド

```bash
pip install -r requirements.txt
pyinstaller build.spec
```

`dist/HospitalSurvey.exe` が生成されます。

## テスト

```bash
python -m unittest discover -s tests -v
```
